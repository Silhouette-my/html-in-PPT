# 放映、讲稿和交付

双击成品 HTML，在右上角点击“演示”。主窗口作为演讲者控制台，另开观众窗口；基础放映支持 `file://`，不需要服务器。只想从某页开始时，先选左侧缩略图，再开始放映。浏览器没有进入全屏也能继续窗口内放映。

## 主窗口看稿，观众窗口只放映

主窗口显示当前页、下一页预览、讲稿、计时和导航。当前页可交互，下一页预览不会推进当前演示。讲稿支持滚动和字号调整；结构化段落、列表及“此处点击下一步”等操作提示来自幻灯片里的同一份 `speaker-note`。

观众弹窗只显示幻灯片及演示效果，不显示讲稿、演讲者工具或下一页预览。两窗口同步页码、逐步展示、黑屏/恢复、模型参数、激光笔和批注。自定义模型需使用模板提供的状态适配接口；任意嵌入页面或第三方脚本的私有状态不会自动同步。关闭观众窗口后，从主窗口重新打开会恢复当前演示状态。

使用扩展显示时，将观众窗口拖到投影屏并全屏，主窗口留在自己的屏幕。镜像显示会让两块屏幕出现同一内容，无法隐藏讲稿。线上会议只共享观众窗口，不共享演讲者主窗口；开播前确认共享预览。

计时首次放映启动，结束时暂停，再次放映继续累计。开始新一轮排练前可重置计时。画笔墨迹只保留在当前页面会话内，关闭 HTML 即丢失。

## 按讲解节奏推进

点击背景、按 → 或 Space，先揭示下一组，全部展开后进入下一页。← 先撤回一组，跨页时回到上一页完整状态。操作图表、模型、输入框或链接不会误翻页。

工作区始终显示全部内容。从工作区开始放映、选择缩略图或直接跳页，目标页从第 0 步开始。“动画”中可关闭逐步显示，或重置当前页步骤；“切换”中可开启淡入，系统的减少动态效果设置优先。

## Windows / macOS 快捷键

| 操作 | Windows | macOS |
| --- | --- | --- |
| 从头放映 | F5 | ⌘⇧Return |
| 从当前页放映 | Shift+F5 | ⌘Return |
| 下一步 / 上一步 | → / ←，Space / PageUp | → / ←，Space / Fn+↑ |
| 首页 / 末页 | Home / End | Fn+← / Fn+→ |
| 指定页 | 数字后按 Enter | 数字后按 Return |
| 结束放映 | Esc | Esc |
| 打印 | Ctrl+P | ⌘P |

两端都可用 G 打开概览、F1 查看帮助。放映中用 B/W 切换黑屏/白屏，L 开关激光笔，P 开关画笔，E 清除本页墨迹。Mac 也可使用 F5/Shift+F5，是否需要 Fn 取决于键盘设置。快捷键被系统占用时用界面按钮。

## 调整工作区

顶部搜索可查命令或按标题、页码找幻灯片。“视图”中可切换备注、标尺、概览与缩放；底部备注条可展开当前页讲稿。侧栏和功能区可以折叠，画布按 16:9 等比适应窗口。

弹簧模拟需要手动点击运行。模型只在可见演示页推进；离页、所有窗口切到后台、黑屏或打印时暂停，回来后手动继续。三维模型支持拖动、滑块、方向键和重置。

## 下载、打印和 PPTX 有什么区别

- **下载 HTML**：保存完整文稿与内嵌资源，不保存临时步骤、墨迹、计时和模型参数。“重命名”改变显示名称和下载副本名，不修改磁盘原文件。
- **打印 / PDF**：显示全部步骤，隐藏工作区、讲稿和墨迹；函数图保留当前曲线，物理/3D 使用静态结构图。检查预览页数并启用背景图形以保留配色。
- **自动导出 PPTX**：每页为一张完整截图，原生备注来自对应 HTML 页的 `speaker-note`，不显示在截图正文中。支持指定页码和按步骤展开；PPTX 正文中的文字、图形与交互不能单独编辑或运行。导出方法见 [PPTX 导出](pptx-export.md)。

导出从 HTML 定义的初始状态开始，不读取另一个已打开窗口里的临时参数。复杂效果应提供稳定的静态导出状态。模型交互仍在配套 HTML 中运行。

## 把文件交给别人

使用自动导出的 `*-bundle.zip`，里面包含 HTML、PPTX 和 `使用说明.txt`。解压后把两者留在同一目录；仅提交 PPTX 仍能查看静态页面，但首页链接需要接收者同时持有 HTML。

在桌面 PowerPoint 的放映模式点击第一页打开 HTML。macOS 首次可能要求选择并授权该文件，Windows 可能显示外部链接提示；由用户确认目标文件。不关闭安全保护；若目标电脑禁止打开 HTML，直接用 PPTX 作静态演示。

PPTX 原生备注可在 PowerPoint 中查看和编辑。修改内容时让 agent 改 HTML，再重新导出，避免讲稿与页面脱节。

## 自动双屏：先选观众屏，再全屏观众窗口

新版 Chrome / Edge 可通过 Window Management API 选择显示器并辅助放置观众窗口。系统需设为“扩展”而非“镜像”；需要用户授权屏幕访问，并允许观众弹窗。浏览器可能不支持从 `file://` 页面请求屏幕管理权限，此时可用本机 HTTP 入口。自动选屏不是普通放映的前提，手动拖动始终可用。

只有需要自动选屏且浏览器不支持 `file://` 屏幕管理时，才需要本机 HTTP 入口。

### Windows：单文件启动器

Windows 10/11 可直接双击 [`scripts/present.cmd`](../scripts/present.cmd)。默认文稿是**相对 CMD 所在目录**的 `../assets/deck-template.html`；只有该文件不存在时才弹出选择窗口。把一个 HTML 文件拖放到脚本上，或使用 `--html`，可优先指定其他文稿。

CMD 与 HTML 是两个独立文件，页面内容从选中的 HTML 读取。启动器使用 Windows 自带的 PowerShell 5.1/.NET，不需要 Node.js、npm、Python 或第三方包，也不会下载启动文件、把 HTML 合并进 CMD 或生成临时 HTML。

从仓库根目录也可使用以下命令。PowerShell 中在路径前加 `./`，例如 `./scripts/present.cmd "presentation.html"`：

```bat
scripts\present.cmd "presentation.html"
scripts\present.cmd --html "presentation.html" --port 8768 --no-open
scripts\present.cmd --browser "C:\Program Files\Google\Chrome\Application\chrome.exe"
scripts\present.cmd --help
```

默认从 `8768` 到 `8778` 依次尝试可用端口，通常复用同一地址以保留屏幕授权；`--port` 可指定固定端口，占用时明确报错。`--no-open` 只启动服务并显示地址。路径包含空格时加引号，支持中文文件名。取消文件选择会直接退出；启动失败时保留错误提示。

启动器优先查找 Edge，再查找 Chrome，也可用 `--browser` 指定路径。它为本次放映打开专用应用窗口，配置保存在 `%LOCALAPPDATA%\html-in-PPT`。只为当前 `http://127.0.0.1:<端口>` 来源启用弹窗与自动全屏，屏幕管理权限仍由浏览器询问。并发启动会使用独立配置；浏览器正常配置、系统注册表与全局策略均无需调整。复制地址到其他浏览器或使用 `--no-open` 时，需按该浏览器的实际权限操作。

终端与初始演示窗口均以选中此 CMD 的资源管理器所在屏幕为准，找不到对应窗口时使用鼠标所在屏幕。终端在该屏幕的可用区域内居中，保留原有大小，超出工作区时缩小；原先已最大化的窗口仍保持最大化。传统 CMD 定位其控制台窗口，Windows Terminal 定位当前标签所属的可见宿主窗口；`--no-open` 也会定位交互终端。启动定位成功后即可自由移动窗口。

初始演示窗口在同一屏幕的可用工作区居中，以 16:9 比例适配大小，保留任务栏和边距；可处理左侧显示器的负坐标及不同缩放。启动阶段仅校正本次浏览器的初始窗口，后续仍可自由移动或调整大小。观众弹窗默认与演示窗口等宽，按 16:9 设置外框并计入浏览器边框；目标屏幕较小时自动缩小。调整演示窗口大小时，未全屏的观众窗口会同步宽度，并限制在其所在屏幕的可用区域内；进入自动双屏后使用所选观众屏全屏。

在系统设置中选择扩展显示，点击页面的“演示”或“演示者视图”，主窗口先进入演示者模式并请求屏幕权限，此时不会打开观众窗口遮挡权限提示。点击浏览器提示中的“允许”后，模板才在另一块屏幕打开观众窗口并请求全屏，讲稿留在主窗口；需要更换观众屏时使用“双屏设置”。权限被拒绝、单屏或 API 不支持时，保留演示者窗口并显示手动操作入口，不自动弹出观众窗口。打开页面本身不会请求屏幕权限。

服务只监听 `127.0.0.1`，只提供选中的 `.html` / `.htm` 文件，不开放文稿目录；外部图片、字体、脚本等相对路径资源不会由启动器提供，请使用自包含 HTML。运行期间保留终端，按 **Q**、**Esc** 或 **Ctrl+C** 一并关闭本次放映浏览器与服务，无需批处理终止确认；直接关闭专用浏览器也会停止服务。修改独立 HTML 后需重启。CMD 传入 `local-present=1` 标记，由模板中的 JavaScript 执行选屏；其他 HTML 需包含相应双屏逻辑。

### Node.js：保留现有命令

开发者及其他平台用户可继续从仓库根目录运行：

```bash
npm run present -- --html "presentation.html"
```

命令启动仅监听 `127.0.0.1` 的服务，并尝试在系统默认浏览器打开文稿。它只提供指定 HTML，不公开整个文件夹。若默认浏览器不支持屏幕管理，将终端显示的地址复制到 Chrome / Edge。服务运行期间保留终端，按 Ctrl+C 停止。服务提供启动时读取的文稿；修改 HTML 后重新启动服务。基础放映不依赖该服务。

需要固定本机端口，或不自动打开浏览器：

```bash
npm run present -- --html "presentation.html" --port 8768 --no-open
```

### 其他入口的自动双屏操作顺序

1. 点击“演示”打开观众窗口，确认两个窗口均正常。
2. 在“双屏设置”中点击“检测屏幕 / 请求权限”，在浏览器提示中允许访问屏幕信息。
3. 选择观众屏，然后单独点击“开始自动双屏”，请求观众窗口在所选屏幕全屏。翻页、步骤和计时仍由主窗口控制。
4. 若弹窗被拦截，允许本页弹窗后重试；若跨屏全屏失败，改用“手动双屏”，把观众窗口拖到目标屏再全屏。确认投影实际显示后再开始讲解。

权限提示没有出现或一直等待时，可关闭设置后重新检测，或直接手动放置窗口。拒绝权限、不支持 API、单屏或镜像模式不会阻止普通双窗口放映。手动移动窗口不要求屏幕管理权限。

Windows：按 `Win+P`，选择“扩展”。macOS：打开“系统设置 → 显示器”，选中外接显示器并设为扩展显示，关闭镜像。系统版本不同可能略改菜单名称。线上会议开始共享时选择“窗口”，指定观众窗口；不要选择整个桌面或演讲者主窗口。自动化模拟测试不等同真实双屏验收；没有在目标设备现场操作时，不声称多屏投影已验证。
