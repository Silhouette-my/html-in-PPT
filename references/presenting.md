# 放映、讲稿和交付

双击成品 HTML，在右上角点击“演示”。只想从某页开始时，先选左侧缩略图，再开始放映。浏览器没有进入全屏也能继续窗口内放映。

## 按讲解节奏推进

点击背景、按 → 或 Space，先揭示下一组内容，全部展开后进入下一页。← 先撤回一组，跨页时回到上一页完整状态。操作图表、模型、输入框或链接不会误翻页。

工作区始终显示全部内容。从工作区开始放映、选择缩略图或直接跳页，目标页从第 0 步开始。“动画”中可关闭逐步显示，或重置当前页步骤；“切换”中可开启淡入，系统的减少动态效果设置优先。

## Windows / macOS 快捷键

| 操作 | Windows | macOS |
| --- | --- | --- |
| 从头放映 | F5 | ⌘⇧Return |
| 从当前页放映 | Shift+F5 | ⌘Return |
| 下一步 / 上一步 | → / ←，Space / PageUp | → / ←，Space / Fn+↑ |
| 首页 / 末页 | Home / End | Fn+← / Fn+→ |
| 指定页 | 数字后按 Enter | 数字后按 Return |
| 结束放映 | Esc | Esc |
| 打印 | Ctrl+P | ⌘P |

两端都可用 G 打开概览、F1 查看帮助。放映中用 B/W 切换黑屏/白屏，L 开关激光笔，P 开关画笔，E 清除本页墨迹。Mac 也可使用 F5/Shift+F5，是否需要 Fn 取决于键盘设置。快捷键被系统占用时用界面按钮。

## 把讲稿留在自己的屏幕

点击“演示者视图”打开独立窗口，查看当前页、下一页、备注和计时。窗口内的导航与听众页同步；当前页跟随揭示步骤，下一页显示完整内容。

允许本页弹窗后再试被拦截的窗口。把演示者窗口留在自己的显示器，只共享听众放映窗口。真正双屏或会议共享时，要在现场检查共享对象。

计时首次放映开始，结束时暂停，再次放映继续累计。开始新一轮排练前可重置计时。画笔墨迹只保留在当前页面会话内，关闭 HTML 即丢失。

## 调整工作区

顶部搜索可查命令或按标题、页码找幻灯片。“视图”中可切换备注、标尺、概览与缩放；底部备注条可展开当前页讲稿。侧栏和功能区可以折叠，画布按 16:9 等比适应窗口。

弹簧模拟需要手动点击运行。离页、切到后台、黑屏或打印时会暂停，回来后手动继续。三维模型支持拖动、滑块、方向键和重置。

## 下载、打印和 PPTX 有什么区别

- **下载 HTML**：保存完整文稿与内嵌资源，不保存临时步骤、墨迹、计时和模型参数。“重命名”改变显示名称和下载副本名，不修改磁盘原文件。
- **打印 / PDF**：显示全部步骤，隐藏工作区、备注和墨迹；函数图保留当前曲线，物理/3D 使用静态结构图。检查预览页数并启用背景图形以保留配色。
- **自动导出 PPTX**：重新加载 HTML 的初始状态，逐页截图，全部步骤可见；物理/3D 使用静态替代。不会捕获你在已打开浏览器里临时调过的参数。导出方法见 [PPTX 导出](pptx-export.md)。

## 把文件交给别人

使用自动导出的 `*-bundle.zip`，里面只有 HTML 和 PPTX。解压后把两者留在同一目录；仅提交 PPTX 仍能查看静态页面，但首页链接需要接收者同时持有 HTML。

在桌面 PowerPoint 的放映模式点击第一页打开 HTML。macOS 首次可能要求选择并授权该文件，Windows 可能显示外部链接提示。不关闭安全保护；若目标电脑禁止打开 HTML，直接用 PPTX 作为静态演示。

PPTX 每页是截图，不能单独修改其中的文字或图表。内容要改时让 agent 改 HTML，再导出到新的目录。
