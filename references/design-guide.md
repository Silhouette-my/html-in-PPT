# 大学 pre 的设计标准

## 先组织论点

8 分钟示例节奏：封面 20 秒；研究问题 50 秒；背景/已有工作 60 秒；方法 70 秒；发现 120 秒（可拆两页）；讨论与局限 80 秒；结论 50 秒；参考文献备查。根据内容调整，不要求每页停留相同时长。

标题优先写结论，例如“反馈越早，修改成本越低”，而不是笼统的“结果分析”。如果证据不足，就用问题或描述性标题，不能为了有力而夸大因果。

## 视觉语言

- 默认画布 1600×900、边缘安全区 80px，标题 56–92px、正文 28–36px、次要标注 20–24px。投影场景保证足够对比度，避免浅灰细字。
- 用一个强调色、一个深色、一个浅色底。字体最多两组，中文使用系统黑体。模板示例是暖白、炭黑与朱红，可按学院或主题调整。
- 每页优先 40–100 个中文字，正文不宜超过约 160 字（参考文献/代码页可例外）。超量应拆页。把解释放进讲稿，但页面自身仍需能看懂论点。
- 设计节奏包括：大标题封面、双栏论证、流程、数据图、关键引文、结论。不要反复使用同一种卡片网格。
- 留白是结构。视觉元素服务论点，不为“看起来很 AI”而添加无关渐变球、玻璃卡片或装饰图标。

## 适用布局

| 内容 | 布局 | 注意 |
| --- | --- | --- |
| 引入问题 | 大字 + 单个概念图 | 封面不要堆摘要 |
| 对比观点 | 两栏对照 + 页底判断 | 两边使用同一比较维度 |
| 方法流程 | 3–5 步横向流程 | 明确输入与输出 |
| 实验结果 | 主图占约 60% + 结论 | 轴、单位、样本、来源完整 |
| 文献评述 | 论点 + 证据 + 局限 | 区分引用与作者解释 |
| 结尾 | 一句话结论 + 下一步 | 让听众能复述核心观点 |

## 动效与图表

默认只用轻微切换反馈，不自动播放持续动画。用 `data-step` 让论点按讲述顺序出现，工作区始终完整可读；不要把一页拆成大量细碎点击。动态图表应表达参数与结果的关系；仿真提供运行、暂停、重置，说明模型方程、单位与数值方法。三维操作提供滑块或键盘等价方式。所有交互都应服务当前论点，不为“展示技术”占用听众注意力。

动态内容必须有可打印的静态表达；Canvas 和 CSS 3D 可用 `.static-effect` SVG 结构图替代。图表数值标签直接显示，不依赖 hover。打印显示所有步骤，不把动画的中途状态当作最终结论。具体声明与生命周期见 `interactive-authoring.md`。表格过密时拆为两页或移至附录。

## 讲稿

每页提供适合口述的说明、预计用时和一句过渡。工作区“备注”显示当前页讲稿；“演讲者视图”另外打开同步窗口，含当前页、下一页、讲稿和计时。提醒演讲者只共享放映画面，把演讲者窗口留在自己的屏幕上。浏览器必须允许弹窗；真正双屏投影需在现场检查共享对象。
